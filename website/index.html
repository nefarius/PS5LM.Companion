Bring your own console

Up and running with Docker.

You’ll need a jailbroken PS5 with PS5LM or PS5LM Plus, ftpsrv, and the pinned nefarius VoidShell fork. The setup guide covers preparing a fresh console.

The Docker image supports linux/amd64 and linux/arm64 only. On a Raspberry Pi, check your OS architecture before installing: a 64-bit OS is required; 32-bit ARM is not supported.

01 / START THE COMPANION

A small container.
A useful companion.

Replace the IP address with your console’s address and unique-secret with your own access token. Keep the data volume for settings and downloads.

View on Docker Hub ↗
TERMINAL / DOCKER
docker run -d --pull always \
  -p 8080:8080 \
  -v ps5lm-companion:/data \
  -e PS5__Consoles__ps5__Host=192.168.1.50 \
  -e Companion__AccessToken=unique-secret \
  containinger/ps5lm-companion
02 / OPEN YOUR BROWSER

Meet your dashboard.

Open http://localhost:8080 on the host, or use its network address from another device. Sign in with the access token you chose.

03 / MAKE IT YOURS

Add a model. Start exploring.

Check console status, browse models, and queue your first transfer. Add more consoles from Manage consoles whenever you’re ready.

Use a trusted network, or put the companion behind a TLS reverse proxy: the access token travels in clear text over plain HTTP. With a reverse proxy, restrict direct access to port 8080 so clients must use HTTPS through the proxy. If the proxy can reach the host’s loopback interface, publish the port with -p 127.0.0.1:8080:8080 instead; otherwise restrict port 8080 to the proxy using firewall or network rules.
